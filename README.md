# 株式自動売買ワークフロー構想

**J-Quants API × Claude AI × kabuステーションAPI（三菱UFJ eスマート証券）**

> ⚠️ 本リポジトリは構想・設計ドキュメントです。自動売買は金融リスクを伴います。実運用前に必ずPhase 1・2で十分な検証を行ってください。

---

## 概要

日本株市場のデータをJ-Quants APIで取得し、Claude AIがテクニカル分析・売買判断を行い、kabuステーションAPIを通じて自動発注するワークフローです。

## タイムライン

| 時刻 | 処理 |
|------|------|
| 08:00 | トリガー起動・データ取得開始 |
| 08:00〜08:10 | J-Quants APIデータ取得 |
| 08:10〜08:20 | テクニカル指標算出 + Claude判断 |
| 08:20〜08:30 | リスクチェック + 発注準備 |
| **08:30** | **kabuステーションAPIで注文送信** |
| 09:00 | 東証 前場寄り付き → 注文執行 |
| 09:00〜15:30 | 監視トリガーが10分〜1時間おきに稼働 |
| 15:30 | 後場引け |
| 16:00 | 引け後トリガー起動・損益集計・Slack報告 |

---

## 取引中監視ワークフロー（監視トリガー）

取引時間中（09:00〜15:30）に定期実行し、以下を判定します。

```
現在値を取得
    │
    ├─ 損切りライン到達    → 即時成行売り注文
    ├─ 利確ライン到達      → 即時成行売り注文
    ├─ 急落検知（X%以上）  → 全ポジション決済 + 当日発注停止
    ├─ APIエラー連続        → 全自動売買を緊急停止
    └─ 異常なし             → 継続監視 → Slack通知（定期報告）
```

## トリガー構成

| トリガー名 | 実行タイミング | 役割 |
|-----------|-------------|------|
| 朝次トリガー | 毎営業日 08:00 JST | データ取得 → 分析 → 発注 |
| 監視トリガー | 09:00〜15:30（1時間おき）| 損切り・緊急停止判断 |
| 引け後トリガー | 毎営業日 16:00 JST | 損益集計 → Slack日次レポート |

> ⚠️ リモートトリガーの最小実行間隔は1時間のため、5〜10分単位の監視が必要な場合はサーバー常駐スクリプトを別途用意する

## 実装フェーズ計画

### Phase 1：分析・通知のみ（発注なし）
**目的：** 判断精度の検証

- J-Quants APIでデータ取得
- テクニカル指標算出
- Claudeによるシグナル生成
- Slackに「もし発注するとしたら」を通知
- **実際の発注は行わない**

### Phase 2：ペーパートレード
**目的：** 損益シミュレーションによる戦略検証

- Phase 1の判断をDBに記録
- 架空の発注・決済を管理
- 損益・勝率・最大ドローダウンを集計
- 十分な精度が確認できたらPhase 3へ

### Phase 3：実口座での自動発注
**目的：** 本番運用

- kabuステーションAPIで実際に発注
- 1日あたりの投資上限金額を必ず設定
- 異常検知時の緊急停止機能を実装済みであること

## 社会動向分析ワークフロー（Phase 0 / 実装済み）

株式売買判断の前段として、**社会・経済・政治の動向を毎日深夜0時に自動収集・分析**するワークフローです。
無料データソースのみを使用します。

### 収集データソース（すべて無料）

| カテゴリ | ソース | 取得方法 |
|---------|--------|---------|
| 国内政治・経済ニュース | NHK News RSS | RSS取得 |
| 国内経済ニュース | Reuters Japan RSS | RSS取得 |
| 首相・官邸動向 | 首相官邸 RSS | RSS取得 |
| 日銀金融政策 | 日本銀行 新着情報RSS | RSS取得 |
| 財務省発表 | 財務省 新着情報RSS | RSS取得 |
| 為替・海外株価 | Yahoo Finance（yfinance） | Python |
| 米国経済指標 | FRED API（無料） | REST API |
| 企業IR・開示情報 | EDINET API（金融庁） | REST API |

### 分析アウトプット

毎日深夜0時に以下を生成し `reports/` に保存・PRを作成：

```
- 本日の重要ニュースTOP5（市場影響度順）
- 為替・海外市場の動向サマリー
- 政治・政策リスク評価（0〜10点）
- 明日の日本株市場への影響予測
- 総合判定：強気 / やや強気 / 中立 / やや弱気 / 弱気
- 注目セクター・銘柄
```

### 実行スケジュール

| トリガー | 実行時刻 | 役割 |
|---------|---------|------|
| 社会動向分析トリガー | 毎日 **00:00 JST** | ニュース・指標収集 → Claude分析 → GitHub PR |
